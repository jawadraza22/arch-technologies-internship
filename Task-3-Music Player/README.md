# 🎵 Music Player Web Application

A modern and responsive web-based music player developed as part of my **Web Development Internship at Arch Technologies**.

The application provides a simple and interactive interface for browsing music, managing playlists, searching songs, categorizing music, and controlling audio playback.

---

## 📌 Project Overview

The **Music Player** is a browser-based music application designed to provide users with an easy and enjoyable way to listen to and manage music.

The project focuses on implementing core music player functionality using frontend web technologies while maintaining a responsive and user-friendly interface.

This project was developed as **Task 3** during my Web Development Internship at **Arch Technologies**.

---

## 🎯 Objectives

The main objectives of this project were:

- Build a web-based music player.
- Implement playlist functionality.
- Add music search functionality.
- Categorize music for easier browsing.
- Implement play and pause controls.
- Implement next and previous/skip functionality.
- Add volume control.
- Create a responsive and attractive user interface.
- Improve JavaScript and DOM manipulation skills.

---

## ✨ Features

### 🎧 Music Library
Browse available songs through an organized music library.

### 📋 Playlist
Display and manage songs through a playlist interface.

### 🔍 Search
Search for songs using keywords such as song title or artist name.

### 🗂️ Music Categories
Organize songs into categories for easier navigation.

### ▶️ Play
Play the selected song directly from the music player.

### ⏸️ Pause
Pause the currently playing song.

### ⏭️ Next / Skip
Move to the next song in the playlist.

### ⏮️ Previous
Return to the previous song.

### 🔊 Volume Control
Adjust the audio volume according to user preference.

### 📱 Responsive Design
The interface adapts to desktop, tablet, and mobile screen sizes.
