# 🌐 Social Network Platform

A full-fledged social networking web application developed as part of my **Web Development Internship at Arch Technologies**.

The platform is designed to provide users with social networking functionality including profiles, posts, comments, likes, friend requests, notifications, privacy settings, multimedia sharing, and real-time updates.

---

## 📌 Project Overview

The **Social Network Platform** is a web-based application designed to simulate the core functionality of a modern social networking platform.

Users can create profiles, publish posts, interact with other users, send friend requests, like and comment on posts, receive notifications, manage privacy settings, and share multimedia content.

The project was developed as **Task 4** during my Web Development Internship at **Arch Technologies**.

---

## 🎯 Objectives

The main objectives of this project were:

- Develop a full-fledged social networking platform.
- Implement user profiles.
- Allow users to create and manage posts.
- Implement comments and likes.
- Implement friend requests.
- Add real-time updates using WebSockets.
- Implement notifications.
- Add privacy settings.
- Support multimedia content sharing.
- Create a responsive and user-friendly interface.
- Understand real-time web application architecture.

---

## ✨ Features

### 👤 User Profiles

Users can create and manage their personal profiles and display relevant information.

### 📝 Posts

Users can create and share posts with other users.

### ❤️ Likes

Users can like posts and interact with content shared by others.

### 💬 Comments

Users can comment on posts and participate in discussions.

### 🤝 Friend Requests

Users can send and manage friend requests to establish connections.

### 🔔 Notifications

Users can receive notifications related to social interactions and activities.

### ⚡ Real-Time Updates

WebSockets are used to provide real-time updates without requiring users to manually refresh the page.

### 🔒 Privacy Settings

Users can manage privacy options and control the visibility of their profile and content.

### 🖼️ Multimedia Sharing

Users can share supported multimedia content such as images.

### 📱 Responsive Interface

The application is designed to work across desktop, tablet, and mobile devices.
